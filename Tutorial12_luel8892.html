3 think+write: Explaining array lengths¶

think + write¶

x[:-1] represents the entire array of x except that the last element is moved to the previous-to-last element.

If I were to replot the graph, except I plotted the derivative as plt.plot(x, dydx), an error message would occur because of the definition of dydx. The definition of dydx only calculates values for an array with 1 less length than the array given. This is because of how we are currently calculating the derivative, which requires the value of x[i+1]. Once we hit the last value of the array, x there is no element with index position [i+1] so we cannot calculate the derivative at the end because it is a discontinuity.

 #function for calculating derivatives
def derivative( f, x, h):
    '''
    -------inputs-------
    
    f= function
    f is a function that you want to take the derivative of
        ie: y=mx+b
    x = float or integer
        The x value at which you want to take the derivative
    h = float or integer > x
        The stepsize to use for the separation of derivatives

    --------function--------

    derivative( f, x, h) calculates that values of the derivtive of
    the function, f at everu x value in the array

    ------output----------

    The function will return a float with the value of the
    derivative at the given value of x rounded to 3 decmil points

    '''
    y1 = float(f(x))
    y2 = float(f(x+h))

    return f"{(y2 - y1)/h:.3f}"
