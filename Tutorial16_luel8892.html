answer for how are .size and .shape different from len()?

len() is just the number of elements in the first dimension of the numpy array

Size is the total number of elements in the numpy array. In a 1-dimensional numpy array, this will be equal to len(), but in higher N dimensions, this will be the product of the lengths of each dimension

shape () is a tuple with the number of dimensions listed in (1st dimension length, 2nd dimension length, 3rd dimension length, Nth dimension length)
